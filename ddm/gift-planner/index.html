How the planner picks

  • It only uses deals that are live in our feed right now, the same ones on Live deals. Every link was checked against the network and opens the merchant's own page.
  • Each person's picks match their interests first, then the published Deal Score. The published Deal Score sets the order.
  • Deals with a minimum order (for example free shipping over a set amount) only show when that person's budget covers it.
  • We spread picks across stores, so two people rarely get the same deal.
  • Estimated savings apply the advertised percentage to each person's budget. Item prices vary, so check the cart before you pay.
