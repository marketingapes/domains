How we verify codes

Short version: every code on Discount Deal Me comes from the store itself, through its affiliate program. We do not post codes we found on forums, social media or other coupon sites.

Where codes come from

Stores that work with us publish their promotions to affiliate networks: CJ (Commission Junction) and Impact. Each promotion is a record with a code field, a start date, an end date and terms written by the store. Our refresh job reads those records through the networks' official APIs and copies the code, dates and terms exactly.

What "verified" means here

  • The code is in the store's own record, in the network's code field. We never type a code in by hand.
  • The record was active, and not past its end date, at our last check. Every page shows when that was.
  • Codes that pass their end date are hidden by your browser at that moment, even between our checks.
  • A code with no end date is dropped if the store has not updated it in over a year, or if its own name points to a season or event that is over (for example a "Memorial Day" code in November).
  • We remove codes that were clearly made for another website, codes aimed only at other countries, and records whose code and description disagree.

What it does not mean

We have not placed a test order with every code. A store can still limit a code to some items, first orders or a minimum spend, and those limits are in the terms we show. We do not publish savings estimates, "success rates", user votes or reviews, because we do not have honest data for them.

When a store has no codes

We say "No verified codes right now" and show the store's current no-code offers if it has any. Pages with very little on them are kept out of search results until there is something useful to show.

How we make money

Store links are affiliate links (#ad). If you buy, we may earn a commission from the store. It never changes your price, which codes we list, or their order. More detail is in how we pick deals.

Found a code that does not work?

Tell us which store and code. We recheck it against the network and remove it if the store has withdrawn it.
